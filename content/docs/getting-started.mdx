<Steps>
<Step>

### Pick a library

every library is published as `every/` followed by its name in kebab-case, like `every/thread` or
`every/better-scale`. its page, under **Libraries** in the sidebar, shows the exact name and the
latest version on ember

</Step>
<Step>

### Add it to your manifest

```toml title="ember.toml"
[dependencies]
Thread = { name = "every/thread", version = "^0.1.0" }
```

```bash
embr install
```

the libraries it depends on are installed with it. `Signal` runs its handlers with `Thread`, so
installing `Signal` also installs `Thread`

</Step>
<Step>

### Require it

the library lands in your packages folder. require it like any other module:

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Thread = require(ReplicatedStorage.Packages.Thread)

Thread.spawn(print, "hello from a recycled thread")
```

</Step>
</Steps>

## Versions

libraries follow [semantic versioning](https://semver.org), and each one has its own version.
below `1.0.0`, a minor bump (`0.1.x` to `0.2.0`) can break the API, so the examples above depend on
`^0.1.0` to get fixes only. read a library's page before moving to its next minor version
