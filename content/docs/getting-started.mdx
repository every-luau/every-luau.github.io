<Steps>
<Step>

### Pick a library

Every library is published under the same name on each registry: `every/` followed by the
library's name in lowercase, for example `every/thread` or `every/signal`. Its page, under
**Libraries** in the sidebar, shows the exact name and latest version on each registry.

</Step>
<Step>

### Add it to your manifest

<Tabs items={['wally', 'pesde', 'ember']}>
  <Tab value="wally">

```toml title="wally.toml"
[dependencies]
Thread = "every/thread@^0.1.0"
```

```bash
wally install
```

  </Tab>
  <Tab value="pesde">

```toml title="pesde.toml"
[dependencies]
Thread = { name = "every/thread", version = "^0.1.0" }
```

```bash
pesde install
```

  </Tab>
  <Tab value="ember">

```toml title="ember.toml"
[dependencies]
Thread = { name = "every/thread", version = "^0.1.0" }
```

```bash
embr install
```

  </Tab>
</Tabs>

Libraries that use other libraries, like Signal which runs its handlers with Thread, install
them for you.

</Step>
<Step>

### Require it

The library is installed in your packages folder (`Packages` with wally). Require it like any
other module:

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Thread = require(ReplicatedStorage.Packages.Thread)

Thread.spawn(print, "hello from a recycled thread")
```

</Step>
</Steps>

## Versions

Libraries follow [semantic versioning](https://semver.org) and each one is versioned on its own.
Below `1.0.0`, a minor bump (`0.1.x` to `0.2.0`) may change the API, which is why the examples
above depend on `^0.1.0`: you get fixes, never breaking changes. Read a library's page before
moving to its next minor version.
