Every is a set of small Luau libraries for Roblox. Each one solves a single problem, is typed for
Luau's new type solver, and is installed on its own, so a project only carries what it uses.

```lua
local Signal = require(Packages.Signal)
local Void = require(Packages.Void)

local died = Signal.new()
local cleanup = Void.new()

cleanup:add(died:connect(function(cause)
	print("died from", cause)
end))

died:fire("lava")
cleanup:clean() -- disconnects everything added to it
```
