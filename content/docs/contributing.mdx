## Setup

Every library lives in the [every](https://github.com/every-luau/every) repository. You need
[lune](https://github.com/lune-org/lune), pinned in its `ember.toml`, and
[just](https://github.com/casey/just), which runs every command below.

<Files>
  <Folder name="every" defaultOpen>
    <Folder name="libraries" defaultOpen>
      <Folder name="Thread" />
      <Folder name="Signal" />
      <Folder name="..." />
    </Folder>
    <Folder name="template" />
    <Folder name="scripts" />
    <File name="justfile" />
  </Folder>
</Files>

- `libraries` holds one folder per library, each one a package of its own.
- `template` is what `just new` copies to create a library.
- `scripts` holds the lune scripts behind the `just` commands.

## Layout of a library

<Files>
  <Folder name="Thread" defaultOpen>
    <Folder name="src" defaultOpen>
      <File name="init.luau" />
    </Folder>
    <Folder name="tests">
      <File name="init.spec.luau" />
    </Folder>
    <Folder name="examples" />
    <File name="fumablox.toml" />
    <File name="ember.toml" />
    <File name="pesde.toml" />
    <File name="wally.toml" />
    <File name="default.project.json" />
  </Folder>
</Files>

| File | What it is for |
| --- | --- |
| `src` | The library itself. |
| `tests` | Its [lest](https://github.com/lest-luau/lest) specs. |
| `examples` | Scripts shown at the bottom of the library's page. |
| `fumablox.toml` | Its `title`, `description` and `emoji` on this site, and how its API reference is generated. |
| `ember.toml`, `pesde.toml`, `wally.toml` | The package on each registry. They always share the same version. |

Libraries require each other as siblings (`script.Parent.Thread`), the way package managers
install them. Add the dependency to all three manifests.

## Commands

```bash
just new Name              # create libraries/Name from the template
just test Signal           # run a library's tests
just test-all              # run every library's tests
just docs Signal           # check its documentation comments
just sourcemap             # let luau-lsp resolve requires between libraries
just site                  # generate the docs and run this site locally
just versions              # every library's version
just bump Signal minor     # bump its version in all three manifests
just release Signal patch  # bump, test and publish to every registry
```

## Documenting

The API reference is generated by [fumablox](https://github.com/metricrb/fumablox) from Moonwave
comments. Only what has a comment is documented:

```lua
--[=[
	@class Thread

	Runs callbacks on a recycled thread instead of creating a new one per call.
]=]
```

Tags such as `@yields`, `@server`, `@client`, `@deprecated` and `@since` show up as badges, and
admonitions (`:::tip`, `:::info`, `:::caution`, `:::warning`, `:::danger`) become callouts:

```lua
--[=[
	:::tip Clean up
	Disconnect the connection when you are done with it.
	:::
]=]
```

Run `just docs <Name>` to catch missing or broken docs before pushing.

## Releasing

CI runs the tests and checks the docs of every library on each push and pull request. Both must
pass before a change is merged.

Once merged, `just release <Name> <major|minor|patch>` bumps the version, tests the library and
publishes it to ember, pesde and wally. The site is rebuilt when CI passes on `main`, so a
library shows up here as soon as it has documented code and a `fumablox.toml`.
